This project is using code from the following Github repository: https://github.com/NWC-CUAHSI-Summer-Institute/cfe_py/blob/main/README.md. 

It consists of a Python implementation of the NWM Conceptual Equivalent (CFE) model. 
More info about the model can be found here: https://github.com/NOAA-OWP/cfe/. 

It also consists of the BMI implementation of CFE, which will not be needed at 
the moment.
